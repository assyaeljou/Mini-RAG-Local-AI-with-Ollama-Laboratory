# Mini-RAG Local AI with Ollama

## Description
A local AI assistant that answers questions using documents with Ollama and Python.

## Technologies
- Python
- Ollama
- Flask
- TF-IDF
- Qwen3.5 and Gemma3

## Features
- Runs locally without cloud services.
- Answers questions about local documents.
- Keeps conversation history.
- Displays response time.

## How to Run

```bash
pip install flask requests scikit-learn
python source/app.py
```

Open: `http://127.0.0.1:5001`
